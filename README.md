# רשימת קניות חכמה

אפליקציית web סטטית בעברית ליצירת רשימת קניות מטקסט או מהקלטה, ניהול מוצרים בדשבורד ושליחה ל-WhatsApp בלחיצה.

## הרצה מקומית

```powershell
python -m http.server 5173 --bind 127.0.0.1
```

ואז לפתוח:

```text
http://127.0.0.1:5173/
```

## הקלטה

הקלטה דרך הדפדפן עובדת רק בדפדפנים שתומכים ב-Web Speech API, בדרך כלל Chrome או Edge. בנוסף, בדפדפן צריך לאשר הרשאת מיקרופון.

בענן חובה להריץ דרך HTTPS. ב-localhost זה אמור לעבוד גם ללא HTTPS, אבל הדפדפן המובנה של Codex עלול לחסום הרשאת מיקרופון.

## פריסה בענן

האפליקציה היא אתר סטטי, לכן אפשר להעלות את כל התיקייה ל-Vercel, Netlify, Cloudflare Pages או GitHub Pages.

### Vercel

1. ליצור פרויקט חדש ב-Vercel.
2. לבחור את התיקייה הזאת כריפו/פרויקט.
3. להשאיר Build Command ריק.
4. להשאיר Output Directory בתור `.`.

### Netlify

1. ליצור Site חדש.
2. לבחור את התיקייה הזאת.
3. Build command ריק.
4. Publish directory: `.`

אחרי הפריסה, לפתוח את כתובת ה-HTTPS של האתר וללחוץ על כפתור ההקלטה.
